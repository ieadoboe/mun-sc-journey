SVG elements

Scalable Vector Graphics are used for vector drawings on HTML pages. Familiarity with the tag namespace and its capabilities is useful for low-level drawing, which you can use in packages such as D3js.

Background

SVG is incorporated into HTML through an extended tag namespace. Before exploring D3.js, we'll get a basic idea of some simple svg elements as they are used in HTML. Here's some references:

  • an in-depth tutorial from MDN is more than you'll need for this course
  • w3schools has more of a try it yourself tutorial
  • a cheatsheet

For this presentation, we'll be using:

  • basic shapes
  • paths
  • groups
  • transformations

We'll be embedding our svg code into our web page html using the <svg> tag.

Paths

The rect, circle, ellipse, line, polyline and polygon elements are stright-forward if you have done any vector graphics or cartesian geometry. The explanation of <path> is a little complex, with its own mini-language for path description as explained in the w3schools tutorial and the MDN tutorial. MDN lists these commands as available for the path description (which is provided by the path d= attribute):

  • M : moveto
  • L : lineto
  • H : horizontal lineto
  • V : vertical lineto
  • C : curveto
  • S : smooth curveto
  • Q : quadratic Bézier curve
  • T : smooth quadratic Bézier curveto
  • A : elliptical Arc
  • Z : close the path

Groups

By using the group tag <g>, we can apply common attributes to every svg element in the group.

Transformations

Groups are really useful in applying transformations to drawing elements. Available transformations include:

  • rotate
  • translate
  • scale
  • skewX and skewY
